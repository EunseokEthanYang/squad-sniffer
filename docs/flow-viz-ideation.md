- 방법: 8개 강제 렌즈(자연/인체/교통/스포츠/음악/주방/만화/기계장치) × 각 2컨셉 = **16개 발산** 후, 서로 다른 관점의 심사 3인(일반인/정보시각화 전문가/해커톤 심사위원장)이 5개 축으로 채점.

## 🥇 1위: 심야 노선도 — 환승 없는 날 (3인 만장일치)

**화면**: 어두운 배경의 지하철 노선도. 아래쪽에 길고 밝은 **초록 1호선(후배 Qwen 1×)** — 접수역→분류역→풀이역→검증역→제출역(종착). 그 위로 짧은 **주황 2호선(선배 2×)**, 맨 위 **거의 꺼져 있는 보라 3호선(선생님 3×)**. 문제 하나하나가 빛나는 점(열차)이 되어 노선을 흐른다.

**이벤트 매핑**
- 접수: 접수역에서 점 생성 / 분류: 분류역 통과 시 색·모양 태그
- 재시도: 검증역 옆 **회차선을 뱅글 도는 점** (+빨간 플래시)
- 에스컬레이션: **점선 환승 통로로 윗 노선 상승**, 요금판 2×/3× 속도 점프
- 불일치: 점이 유령처럼 **둘로 갈라져** 깜빡 → **소등돼 있던 3호선 전체에 불이 켜지며** 환승 (데모의 클라이맥스)
- 손절: 검증역 **비상구(초록 러닝맨)** 로 빠져나가 회색 우회로로 제출
- 제출: 종착역 흡수 + 초록/빨강 링
- 누적 비용: 요금판 + **노선 굵기/발광이 이용량 누적** — 데모가 끝나면 1호선만 두껍게 빛나는 그림이 남는다

**심사평 요지**: "노선도는 학습 비용 0의 다이어그램 모국어 — 경로·분기·회차·환승·종착이라는 흐름의 문법 전부가 이미 기호로 존재한다. 은유가 얇아서 기술 메시지를 절대 잡아먹지 않고(사실상 흐름도 그 자체), 구현 리스크 최저." (전문가: "모든 잉크가 정보다. 소등된 3호선은 '일어나지 않은 일'을 잉크 0으로 보여주는 가장 정직한 장치.")

**구현**: 정적 SVG + getPointAtLength 점 이동. 1~2일. 실패 위험 전 후보 중 최저.

## 심사단 공통 결합 제안 → 최종 합성안

> **본체 = 심야 노선도** 에 아래 3개를 이식:
> 1. **기계식 롤링 요금판 + 운행 장부** (7위 '미터기 내비'에서) — 팀명 Taximeter 서사가 공짜로 붙음 (심사 1·3 공통 제안, 추가 공수 반나절)
> 2. **제출역 옆 접시탑** (5위 '회전초밥'에서) — 문제별로 사용 노선 색 블록이 쌓임. 발표 마지막에 화면을 멈춰도 **접시탑 하나가 비용 분포 차트로 남는다** (심사 1·2 공통 제안)
> 3. **소등 3호선 클라이맥스 연출 강화** — "3호선 개통 0회" 배지, 점등 순간의 화면 술렁임 (전원 강조)

## 차점 후보 메모 (조커로 보관)

- **케이블카(2위)**: 감정 드라마 최강 — 텅 빈 정상행 케이블, 짚라인 손절 활강. 연출 시간이 실제 로그 속도를 못 따라갈 위험.
- **투르 고도 프로필(3위)**: 이미 검증된 스포츠 데이터 그래픽 장르 — '그림'이 아니라 '차트'로 읽힘. 헬기 회수 = 손절.
- **웹툰(4위)**: 한국 심사위원에게 모국어급. 에피소드 길이 = 비용. DOM+CSS만으로 반나절 구현. **발표자료·제출문서용 정적 포맷으로 최고**.
- **척수 반사궁(6위)**: "뜨거운 냄비에서 손 떼는 데 뇌가 필요 없다" — 핵심 메시지의 가장 정확한 철학적 번역. 발표 오프닝 멘트로만 훔쳐도 가치 있음.

## 기존 교실 도트게임과의 관계 (선택지)

1. **투트랙**: 노선도 합성안 = 메인 "관제 뷰"(심사 요건 충족: 흐름·비용·정직성), 교실 게임 = 부스 인터랙션(발 멈추게 하는 힘, 대화·문제내기 체험) — 토글 또는 나란히
2. **교체**: 게임 폐기, 노선도만
3. **유지**: 게임만 계속

권장: **1번 투트랙**. 이미 만든 자산이 살고, 심사 기준(흐름의 정직한 시각화)과 부스 후킹(게임)을 각자 잘하는 화면에 맡긴다.
